# ============================================================================
#  scripts/dist-manifest.txt - WHAT SHIPS INSIDE A vncode DISTRIBUTION.
#
#  Read by BOTH distribution halves - scripts/dist.ps1 (Windows) and
#  scripts/dist.sh (macOS/Linux) - so the two cannot drift: there is one list of
#  what a distribution contains, and the tracked check
#  scripts/checks/check-dist-layout.mjs fails when a bundle appears under
#  packages/ that this list does not carry.
#
#  WHY A DISTRIBUTION IS A FOLDER - AND ALSO ONE FILE
#  --------------------------------------------------
#  app/ is a LAUNCHER, not a bundle: the shell binary walks up for
#  .dsh-version.json, runs the pinned `npx @deepseek-ai/dsh@<pin> web --no-open`
#  and shows that URL in a native window. The plugins are not compiled into it -
#  the web profile installs every bundle as a LIVE LINK into packages/, so the
#  folder IS the application. Ship the folder, keep it in place, click it.
#
#  The single-file build (vncode-<version>-<rid>.exe on Windows, .run
#  elsewhere) does not change any of that. It carries THIS folder inside itself,
#  unpacks it into a stable per-user directory on its first run, and then runs
#  the unpacked folder's own START-HERE - so what it unpacks is exactly the list
#  below, because the file is this list zipped and appended to the shell binary.
#
#  SO WHAT MUST ALWAYS BE HERE
#  ---------------------------
#  packages/ (every bundle, live-linked by the profile), .dsh-version.json (the
#  shell has NO fallback pin and refuses to start without it), the installer
#  scripts, and the built shell binary - which the dist script copies in itself
#  as <vncode.exe | vncode>, so it is deliberately NOT listed below.
#
#  SYNTAX - one rule per line, '#' starts a comment, blank lines are ignored:
#
#    include  <path>     a FILE is copied as is; a DIRECTORY is walked and every
#                        file under it is copied, minus the skip rules
#    skipdir  <name>     never ship a directory with this BASENAME, at any depth
#    skippath <relpath>  never ship this path, or anything under it
#    skipfile <glob>     never ship a file whose BASENAME matches this glob
#
#  SKIP RULES WIN over include rules, whatever order they appear in.
# ============================================================================

# --- the application itself -------------------------------------------------
include packages
include .dsh-version.json

# --- launching and maintaining it -------------------------------------------
# EVERY launcher ships inside scripts/ - the repository root carries no .bat and
# no .sh at all - so this ONE include carries the entry points (install,
# uninstall, run-web, run-desktop and the console twins), the PowerShell and
# POSIX workers and the shared console layer. It also carries the generated
# START-HERE's own dependencies, which is what makes `include scripts` alone
# enough for a recipient to install and run the folder.
include scripts
# The desktop launcher ships too. In a distribution it runs the built shell in
# the folder ABOVE scripts\ and needs no Rust; see its own header for why the
# presence of vncode.exe, and not a Cargo.toml, is what decides which path it
# takes.

# --- what a reader needs ----------------------------------------------------
include README.md
include LICENSE
include SECURITY.md
include docs

# --- the shell: SOURCE, because the release compiles nothing -----------------
# A distribution no longer ships a built vncode.exe. The release mode is
# `-NoShell` (see docs/RELEASE.md and docs/DISTRIBUTE.md), which assembles this
# same folder with the shell left as SOURCE and no binary at all - so what a
# recipient downloads is plain JavaScript plus this tree, and NOTHING has to be
# compiled to run it: the browser path (START-HERE -> scripts/run-web) needs only
# Node.js.
#
# app/src-tauri is the Rust source of the native window (the three .rs files,
# build.rs, Cargo.toml, Cargo.lock, tauri.conf.json), app/src-tauri/icons is what
# tauri-build compiles into the binary's resources, and app/ui is the splash page
# `frontendDist` folds in. All of it is 13 files and ~300 KB, so shipping it
# costs nothing and buys the thing a source release has to have: somebody who
# wants the window can run `cargo build --release` in the folder they downloaded.
# `target/` (the 1 GB+ Rust build tree) and `gen/` (tauri-build's regenerated ACL
# schemas) are still skipped below - they are OUTPUT, not source.
include app
# The source tree's own README stays; it is the file that explains the launcher.
include app/README.md

# --- the branding source (dsh-themes inlines assets/vncode.svg) ---------
# One file, not the folder: assets/ also holds the screenshots the pack's own
# Screenshot control wrote there, and those are somebody's machine, not content.
include assets/vncode.svg

# ============================================================================
#  THE SKIP RULES.
# ============================================================================

# Build output and per-machine trees. `node_modules` is the big one: the three
# vendor/ workspaces under packages/ hold 204 MB of build INPUTS for artifacts
# that are already committed under lib/vendor/ - shipping them would multiply
# the archive by twenty for nothing. `target` is the shell's 1 GB+ Rust build
# tree; `gen` is tauri-build's regenerated ACL schemas; `tools` is where the
# installer bootstraps pnpm; `.scratch` is this machine's cargo/pnpm scratch.
skipdir node_modules
skipdir target
skipdir gen
skipdir tools
skipdir .scratch
skipdir .git
skipdir dist

# Nothing machine-local or generated-log-shaped.
skippath docs/diagrams
skipfile *.log

# --- nothing that is about THIS machine or its credentials -------------------
# Neither is in the tree today, and that is the point: `include packages` and
# `include scripts` walk whatever is there, so a stray `node_modules` or a
# `.env` dropped beside a package would otherwise be copied into the folder that
# gets handed to somebody. The output is checked for credential-shaped names
# too (scripts/dist.ps1 Assert-NoSecrets), but the cheapest place to stop a file
# is here, where it is never read at all.
skipdir node_modules
skipfile .env
skipfile .env.*
skipfile *.pem
skipfile *.key
skipfile .credentials.yaml
skipfile *.credentials.yaml

# --- the DISTRIBUTER is not part of a distribution ---------------------------
# The folder is the PRODUCT; these are the factory that makes it. A recipient
# gets START-HERE.bat and does not need the tool that assembled the folder - and
# docs/DISTRIBUTE.md says so out loud ("re-run the distributer in the source
# repository to change it"). They are named here rather than simply left out
# because all of them DO exist under scripts/ and `include scripts` would
# otherwise sweep them in; a build tool inside the thing it builds invites a
# nested dist/ inside a distribution.
#
# One entry point per host, plus the worker each one calls - three files, and
# no forwarders: `run-dist.bat` is the Windows entry point the maintainer
# double-clicks, `run-dist.ps1` is its worker, and `dist.sh` is the POSIX half
# doing the same work itself. Excluding the workers but shipping the entry point
# would be worse than shipping all of it: a recipient could double-click
# scripts\run-dist.bat and get a missing-worker error rather than the app.
skippath scripts/dist.ps1
skippath scripts/dist.sh
skippath scripts/run-dist.bat
skippath scripts/run-dist.ps1

# --- maintainer tooling is not part of a distribution ------------------------
# `include scripts` sweeps the whole folder in, and three things under it are
# the workshop rather than the product. scripts/checks runs AGAINST A CHECKOUT -
# it reads packages/, the Rust source and a git history, none of which a
# distribution promises. scripts/sync-vendored.ps1 moves the vendored forks
# forward and wants pwsh on every host. scripts/make-desktop-icon.mjs regenerates
# app/src-tauri/icons, which is itself not shipped - and would leave a recipient
# holding a generator whose only output they do not have.
skippath scripts/checks
skippath scripts/sync-vendored.ps1
skippath scripts/make-desktop-icon.mjs

# Nothing with an editor's or the OS's fingerprints on it.
skipfile .DS_Store
skipfile Thumbs.db
skipfile desktop.ini
